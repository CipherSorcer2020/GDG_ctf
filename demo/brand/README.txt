PUT YOUR CLUB LOGO HERE
=======================
Drop your logo into this folder, named one of:

    logo.svg   (best - stays sharp everywhere)
    logo.png   (use a transparent background, at least 256 px tall)
    logo.webp / logo.jpg

Refresh the page and it replaces the placeholder in the header, the lobby,
the admin panel, the projector scoreboard and the browser tab icon.
Until then a generic placeholder is shown. No code changes needed.
